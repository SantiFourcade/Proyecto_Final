# Proyecto_Final
Proyecto Final de Carrera en Ingeniería ELectronica, UNR - FCEIA
Autores: Santiago Fourcade y Brian Curti
Director: Ing. Daniel Marquez
Asesor: Hector Coscia
Abstract: Red de nodos que comunican a un nodo central, en primera instancia se obtienen datos de un motor y con estos datos se genera un modelo del motor que se integra en el nodo central, comparando los datos reales con los predecidos de comportamientos normal se generan alertas del estado del sistema.
